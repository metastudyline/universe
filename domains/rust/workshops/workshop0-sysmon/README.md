# 0段实战工坊：手写跨平台终端实时系统与内存监控器 (Sysmon)

> **前置知识**：已完成 R00~R13 物理内存与基础语法 · **预计耗时**：2 小时

---

## 🛠️ 项目目标

脱离简单语法 Demo，亲手构建一个属于你自己的极简终端系统监控工具：
1. **内存透视**：实时获取物理内存与栈堆分配情况；
2. **环形队列**：在栈上实现零分配的 `RingBuffer<30>`；
3. **终端火花图**：用 Unicode 字符绘制动态 CPU 波动波形图。

---

## 🚀 快速启动

在终端运行以下命令即可生成本地练习工程：

```bash
./studyline workshop init workshop0-sysmon
```
