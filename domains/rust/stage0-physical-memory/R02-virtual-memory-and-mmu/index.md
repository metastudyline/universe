## 💡 1. 生活物理比喻：城市地籍门牌号 vs 真实物理宗地

每个程序以为自己独占了整个电脑的所有内存，这是怎么做到的？

```
+-------------------------------------------------------------------------+
| 🏠 虚拟地址 (Virtual Address) ──「城市地籍门牌号」                       |
| · 每个小区（进程）内部都有自己的「1号楼101室」（48 位连续地址空间）；      |
| · 每个人写信只要填自己小区的门牌号，完全不需要关心别人家在哪里。         |
+-------------------------------------------------------------------------+
                                    ↓ (经过房管局地籍转译)
+-------------------------------------------------------------------------+
| 🏢 内存管理单元 (MMU 硬件) ──「城市房管局地籍中心」                     |
| · 动态转译：把门牌号通过四级页表（PML4➔PDPT➔PD➔PT）换算成真实 GPS 经纬度；|
| · 荒地补办：如果访问未开发的土地，暂停业务派工补录（缺页异常 Page Fault）； |
| · 禁区拦截：如果擅闯政府军事禁区或写保护红线，直接拉响防空警报（SIGSEGV）！|
+-------------------------------------------------------------------------+
                                    ↓ (物理落地)
+-------------------------------------------------------------------------+
| 🌲 物理地址 (Physical DRAM) ──「真实地理经纬度宗地」                    |
| · 散落分布：你的第 1 页和第 2 页内存在物理内存条上可能相隔十万八千里！    |
+-------------------------------------------------------------------------+
```

## 🛠️ 2. 完整可运行代码：亲眼透视 64 位虚拟地址分布

```rust
fn main() {
    // 1. 栈变量：位于高位虚拟地址 (0x7FFE...)
    let stack_val: i32 = 42;

    // 2. 堆变量：位于中位虚拟地址 (0x6000... 或 0x55FA...)
    let heap_box = Box::new(100);

    // 3. 只读代码段函数指针：位于低位虚拟地址 (0x5555... 或 0x1000...)
    let code_ptr = main as usize;

    println!("✦ 64 位进程虚拟地址空间分布透视:");
    println!("  [高位] 栈内存地址 (Stack) : {:p}", &stack_val);
    println!("  [中位] 堆内存地址 (Heap)  : {:p}", heap_box);
    println!("  [低位] 代码段地址 (Code)  : 0x{:x}", code_ptr);
}
```

### 预期输出：
```text
✦ 64 位进程虚拟地址空间分布透视:
  [高位] 栈内存地址 (Stack) : 0x7ffee...
  [中位] 堆内存地址 (Heap)  : 0x60000...
  [低位] 代码段地址 (Code)  : 0x10000...
```

## 💥 3. 故意写错：编译器与 MMU 在拦截什么？

如果试图直接解引用一个凭空捏造的野指针地址：

```rust
fn main() {
    let raw_ptr = 0xDEADBEEF as *const i32;
    // 💥 试图读取未映射的荒地虚拟地址！
    // let val = *raw_ptr; 
}
```

### 真实报错现场：
```text
error[E0133]: dereference of raw pointer is unsafe and requires unsafe function or block
 --> src/main.rs:4:15
  |
4 |     let val = *raw_ptr;
  |               ^^^^^^^^ dereference of raw pointer
```

### 👨‍⚕️ 医生人话诊断与解药：
- **人话翻译**：`0xDEADBEEF` 这个门牌号在房管局（MMU）里根本没有对应的物理土地！在 Safe Rust 中编译器静态禁止解引用裸指针；如果在 Unsafe 中强行读取，CPU 会立刻抛出 **SIGSEGV 段错误（Segmentation Fault）** 崩溃！
- **修复方案**：始终使用 Rust 经过生命周期与借用检查器验证的合法引用（`&T` 或 `Box<T>`），永远不要手动捏造裸地址。

## 🎯 5. 动手通关小实验 (Micro-Quest)

请声明一个 `String` 并分别打印它**在栈上的指针地址（&s）**与**在堆上的真实数据地址（s.as_ptr()）**：

```rust
fn main() {
    let s = String::from("Hello MMU");
    println!("栈上号码牌地址: {:p}", &s);
    println!("堆中真实内容地址: {:p}", s.as_ptr());
}
```
