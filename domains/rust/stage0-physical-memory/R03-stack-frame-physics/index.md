# R03: 栈帧（Stack Frame）的物理本质：RSP 指针、调用规约与局部变量确定性销毁

> **适合人群**：想要理解为什么函数局部变量退出就消失的初学者 · **预计耗时**：25 分钟

---

## 💡 1. 生活物理比喻：手风琴风箱压伸与按需伸缩栈顶

函数调用的栈内存开销为什么是“零成本”？因为它就像拉伸和压缩手风琴：

```
+-------------------------------------------------------------------------+
| 🪗 步骤 1: 函数调用 ──「拉开手风琴风箱」(`subq $32, %rsp`)               |
| · 琴身两端被双手锁死：`%rbp`（栈底基址）与 `%rsp`（当前栈顶）；           |
| · 拉开风箱，空间瞬间开辟（单条 CPU 减法指令，耗时 0.3ns）；              |
| · 在风箱内部整齐摆放当前乐章的局部变量。                                 |
+-------------------------------------------------------------------------+
                                    ↓ (函数执行完毕)
+-------------------------------------------------------------------------+
| 🎶 步骤 2: 函数返回 ──「双手一合合拢风箱」(`movq %rbp, %rsp; ret`)        |
| · 双手轻轻合拢，风箱空间瞬间归零；                                       |
| · 里面的局部变量在物理上直接坍塌失效，完全不需要垃圾收集器来打扫！         |
+-------------------------------------------------------------------------+
```

## 🛠️ 2. 完整可运行代码：亲眼看清手风琴压栈过程

```rust
fn child_function(depth: usize) {
    let local_var = 100 + depth;
    println!("  [深度 {} 压栈] 局部变量地址 (RSP 附近): {:p}", depth, &local_var);
    if depth < 3 {
        child_function(depth + 1);
    }
    // 函数返回时，风箱合拢，local_var 自动消失！
}

fn main() {
    println!("✦ 栈帧压栈与回弹过程透视 (栈向低地址增长):");
    child_function(1);
}
```

### 预期输出：
```text
✦ 栈帧压栈与回弹过程透视 (栈向低地址增长):
  [深度 1 压栈] 局部变量地址 (RSP 附近): 0x7ffee...
  [深度 2 压栈] 局部变量地址 (RSP 附近): 0x7ffee... (地址变小)
  [深度 3 压栈] 局部变量地址 (RSP 附近): 0x7ffee... (地址更小)
```

## 💥 3. 故意写错：试图从合拢的风箱里拿走东西 (E0515 报错医生)

如果我们试图从函数中返回指向其局部变量的引用：

```rust
fn broken_function() -> &String {
    let s = String::from("临时文字");
    &s // 💥 试图把合拢后已经不存在的栈地址交出去！
}

fn main() {
    let _r = broken_function();
}
```

### 真实报错现场：
```text
error[E0515]: cannot return reference to local variable `s`
 --> src/main.rs:3:5
  |
3 |     &s
  |     ^^ returns a reference to data owned by the current function
```

### 👨‍⚕️ 医生人话诊断与解药：
- **人话翻译**：手风琴一合拢（函数返回），`s` 所在的栈帧就被物理抹平了！如果把 `&s` 指针传给外部，外部读到的就是一堆乱码废墟（**Stack UAF 悬垂指针**）！
- **修复方案**：不要返回引用 `&String`，直接把房产证原件交出去，返回拥有所有权的 `String`：
  ```rust
  fn correct_function() -> String {
      let s = String::from("临时文字");
      s // ✅ 转移所有权，通过！
  }
  ```

## 🔬 4. 底层内存物理真实现场

```
高地址 (栈底 %rbp)
+-----------------------+
| 返回地址 (Return Rip) | ── 函数执行完跳回哪一行
| 旧基址指针 (%rbp)     |
| 局部变量 local_var    |
+-----------------------+ <── 当前栈顶 %rsp (低地址)
```
