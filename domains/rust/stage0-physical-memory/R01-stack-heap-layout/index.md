## 💡 1. 生活物理比喻：托盘餐厅 vs 仓库货架

计算机的物理内存其实一点也不神秘，它就像现实生活中的两个典型储物场所：

```
+-------------------------------------------------------------------------+
| 🍽️ 栈内存 (Stack) ──「托盘快餐厅」                                      |
| · 排队自取：盘子一个压一个往上叠（后进先出 LIFO）；                        |
| · 尺寸固定：每个盘子大小在出厂时就完全固定（比如 i32 固定 4 字节）；       |
| · 速度极快：拿取只需要移动指针（`sub rsp, 32`），单周期完成！            |
+-------------------------------------------------------------------------+
                                    vs
+-------------------------------------------------------------------------+
| 🏬 堆内存 (Heap) ──「大型物流仓库」                                      |
| · 领号码牌：大件、尺寸可变的货物（如长文章 String、变长 Vec）进仓库保管； |
| · 凭票取货：仓库管理员发给你一张带地址的「号码牌」（指针），号码牌放在栈中；|
| · 存在开销：需要找空货架（分配器寻址）和排队登记（锁开销）。              |
+-------------------------------------------------------------------------+
```

## 🛠️ 2. 完整可运行代码：看清栈与堆的配合

```rust
fn main() {
    // 1. 纯栈数据 (Stack): 托盘餐厅的小碟子，大小确定 (4字节)
    let a: i32 = 42;
    let b: i32 = 100;
    println!("栈上的基础数值: a = {}, b = {}", a, b);

    // 2. 堆数据 (Heap): 大件包裹，栈上拿号码牌，真实内容在仓库
    let mut text: String = String::from("StudyLine");
    println!("堆字符串初始内容: {}", text);

    // 仓库扩容：往堆字符串追加内容
    text.push_str(" 知识宇宙");
    println!("追加后内容: {}", text);
}
```

### 预期输出：
```text
栈上的基础数值: a = 42, b = 100
堆字符串初始内容: StudyLine
追加后内容: StudyLine 知识宇宙
```

## 💥 3. 故意写错：在栈上放一个无限套娃的盒子？

如果我们试图在栈上定义一个“自己包含自己”的结构体，会发生什么？

```rust
// 💥 错误示范：无限套娃
struct RussianDoll {
    inner: RussianDoll, // 编译器：这个结构体到底要占用多少字节栈内存？！
}

fn main() {
    // 无法计算尺寸
}
```

### 真实报错现场：
```text
error[E0072]: recursive type `RussianDoll` has infinite size
 --> src/main.rs:1:1
  |
1 | struct RussianDoll {
  | ^^^^^^^^^^^^^^^^^^ recursive type has infinite size
2 |     inner: RussianDoll,
  |     ------------------ recursive without indirection
  |
help: insert some indirection (e.g., a `Box`, `Rc`, or `&`) to break the cycle
  |
2 |     inner: Box<RussianDoll>,
  |            ++++           +
```

### 👨‍⚕️ 医生人话诊断与解药：
- **人话翻译**：栈内存要求所有变量在编译期必须知道**确切的大小**！无限套娃的结构体大小是无穷大，栈托盘放不下！
- **修复方案**：套一个 `Box`（把它放到堆仓库，栈上只放 8 字节的号码牌指针）：
  ```rust
  struct RussianDoll {
      inner: Option<Box<RussianDoll>>, // ✅ 大小固定为 8 字节指针，通过！
  }
  ```

## 🔬 4. 底层内存物理真实现场

当我们创建 `let text = String::from("Hi");` 时，内存长这样：

```
栈内存 (Stack - 固定 24 字节)                堆内存 (Heap - 动态大小)
+-------------------------------+           +-------------------+
| ptr: 0x55FA... (堆地址指针 8B) | ────────> | 'H' 'i' (2 字节)  |
| cap: 2         (容量 8B)      |           +-------------------+
| len: 2         (当前长度 8B)  |
+-------------------------------+
```
