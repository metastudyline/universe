## 💡 1. 生活物理比喻：带封条的储物盒

很多初学者第一次学 Rust，一看到“变量、不可变性、静态类型”就觉得头大。其实它的本质就像整理房间：

```
+-------------------------------------------------------------+
| 📦 模式 A: 带封条的透明储物盒 (`let x = 5;`)                  |
| 贴上「封条」，你可以透过透明窗看它（读取），但不能再往里塞新东西。|
+-------------------------------------------------------------+
                            vs
+-------------------------------------------------------------+
| 🧰 模式 B: 可开合的扣环盒 (`let mut x = 5;`)                  |
| 明确加上 `mut` 扣环，代表这是一个以后会被拿出来换新东西的盒子。  |
+-------------------------------------------------------------+
```

> **为什么 Rust 要这么设计？**  
> 在过去的 C 语言或 Python 中，任何人在任何地方都可以偷偷改掉你的变量，导致程序莫名其妙崩溃。Rust 的原则是：**除非你明确贴上 `mut` 标签，否则默认绝不允许乱改！**

## 🛠️ 2. 完整可运行代码：你的第一行 Rust

请把下面这段代码完整复制到你的编辑器，或在终端直接运行：

```rust
fn main() {
    // 1. 贴封条的只读储物盒（不可变变量）
    let project_name = "StudyLine";
    println!("✦ 欢迎来到 {} 知识宇宙！", project_name);

    // 2. 扣环盒：允许修改的变量（加了 mut）
    let mut learner_xp = 0;
    println!("初始经验值: {} XP", learner_xp);

    // 获得经验，修改变量
    learner_xp += 100;
    println!("完成第一个实验后经验值: {} XP 🚀", learner_xp);
}
```

### 预期输出：
```text
✦ 欢迎来到 StudyLine 知识宇宙！
初始经验值: 0 XP
完成第一个实验后经验值: 100 XP 🚀
```

## 💥 3. 故意写错：编译器在冲你吼什么？

在 Rust 中，**编译器不是你的考官，而是你的私人医生**。我们故意写一段错误代码来体验：

```rust
fn main() {
    let money = 100; // ⚠️ 注意：这里没有加 mut（带封条）
    money = 200;     // 💥 试图往带封条的盒子里硬塞新钱！
}
```

### 真实报错现场：
```text
error[E0384]: cannot assign twice to immutable variable `money`
 --> src/main.rs:3:5
  |
2 |     let money = 100;
  |         -----
  |         |
  |         first assignment to `money`
  |         help: consider making this binding mutable: `mut money`
3 |     money = 200;
  |     ^^^^^^^^^^^ cannot assign twice to immutable variable
```

### 👨‍⚕️ 医生人话诊断与解药：
- **人话翻译**：你第 2 行把 `money` 声明成了只读盒子，第 3 行却想重新给它赋值！
- **修复方案**：按照编译器提示的 `help`，在第 2 行加上 `mut` 即可：
  ```rust
  let mut money = 100; // ✅ 修好啦！
  ```

## 🔬 4. 底层内存真实现场

当我们写下 `let x = 42;` 时，计算机硬件里到底发生了什么？

```
栈内存 (Stack Memory - 地址 0x7FFE...)
+--------------------+
| 变量名: x          |
| 内存类型: i32 (4字节)| ── 写入二进制: 00000000 00000000 00000000 00101010
| 状态: 只读 (IMMUT) |
+--------------------+
```

- 它在栈内存上占用了整整 **4 个字节（32 bits）**；
- 编译器在编译完成之后，如果发现没有任何修改，会直接把这个数字**内联到 CPU 寄存器**中，运行速度达到物理极限。

## 🎯 5. 动手通关小实验 (Micro-Quest)

请修改下面的代码，声明一个可变生命值 `health`，受到 20 点伤害后打印出 `剩余生命值: 80`：

```rust
fn main() {
    // 任务：给 health 加上正确的修饰符，并完成减法
    let mut health = 100;
    health -= 20;
    println!("剩余生命值: {}", health);
}
```
