# R20: 0段出段综合大考：物理内存模型与内存安全发生学

> **考核定位**：0段 20 讲全景因果闭环考核 · 栈堆物理本质 · 内存安全发生学

---

## 1. 出段大考说明

本节点为 **Rust 系统级第一性原理大系 0 段出段判据**。
必须在理解底层硬件（寄存器、栈帧、堆分配器、Cache Line）与 C 语言内存缺陷（UAF、Double Free、数据竞争）的基础上完成闭卷考核。

---

## 2. 核心知识拓扑自查

1. **硬件维度**：
   - 栈指针（RSP）单周期压栈与弹栈；
   - 堆分配器（`jemalloc`）的物理寻址与锁竞争；
   - 64-Byte Cache Line 的空间局部性。
2. **安全发生学**：
   - 指针别名与就地突变的冲突；
   - 仿射类型系统的数学基础。
