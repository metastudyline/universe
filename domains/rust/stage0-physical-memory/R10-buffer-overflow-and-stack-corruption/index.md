# R10: 经典缺陷发生学 IV：缓冲区溢出（Buffer Overflow）与栈破坏攻击

> **一手文献与源码锚点**：Aleph One (1996) *Smashing The Stack For Fun And Profit* (Phrack 49, Article 14) · CWE-120: Buffer Copy without Checking Size of Input

---

## 1. 一手攻击物理模型：栈帧内存被连续冲垮

```
高地址
+-------------------------------------------------------------+
| 调用者函数返回地址 (Saved RIP: 8 Bytes)                      | ➔ 被溢出数据覆盖为攻击者 Shellcode 地址！
+-------------------------------------------------------------+
| 调用者栈底基址 (Saved RBP: 8 Bytes)                         | ➔ 被溢出数据覆盖
+-------------------------------------------------------------+
| 局部字符数组 char buffer[16] (16 Bytes)                     | ➔ 写入 32 字节数据产生溢出 ↑
+-------------------------------------------------------------+
低地址 (RSP 栈顶)
```

- **Rust 的双重铁律**：
  1. 默认强制执行静态与动态**边界检查（Bounds Checking）**；
  2. 迭代器（Iterator）在编译期被 LLVM 证明无越界，完全消除边界检查指令，达成 0 额外 CPU 周期损耗。

---

## 2. 形式化论证三段论 (Formal Syllogism)

- **大前提 ($P_1$)**：若数组访问允许直接退化为无长度界限的裸指针算术，则任何越界写入都将物理破坏相邻内存与控制流数据。
- **小前提 ($P_2$)**：Rust 切片（Slice `&[T]`）在物理上由 16 字节胖指针（8 字节指针 + 8 字节长度 `len`）构成，并在每次直接索引时验证 $i < \text{len}$。
- **归谬 ($R$)**：若为了所谓的“极致性能”完全废除边界检查且缺乏证明，则软件将被缓冲区溢出与远程攻击永远缠绕。
- **结论 ($C$)**：∴ 结合切片长度绑定与现代编译器边界检查消除（BCE Pass），是兼得绝对安全与满血性能的唯一路径。
