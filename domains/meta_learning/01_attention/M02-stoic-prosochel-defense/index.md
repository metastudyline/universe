# M02: 注意力的道德史：从斯多葛 Prosochē 城墙到奥古斯丁的撕裂

## 1. 历史语境与问题发生学

公元 1 世纪，罗马帝国。一个被主人打断双腿的奴隶爱比克泰德（Epictetus），在剥夺了一切物质自由与身体完整性的极端绝境下，发明了一套关于注意力的终极防御技术：**Prosochē（专注的精神修炼）**。

```
+-------------------------------------------------------------+
| 斯多葛注意力三重防火墙 (The Stoic Prosochē Defense)        |
+-------------------------------------------------------------+
|  Level 1: prosochē tōn phantasiōn (审查外部输入的表象与刺激)   |
|           ⬇ 拦截：未经审视的通知与诱惑不得入内              |
|  Level 2: prosochē ton logismōn   (监控内在升起的念头与杂思)   |
|           ⬇ 觉察：如猫捕鼠，念头一动即行克治                |
|  Level 3: prosochē ton hormōn     (管理付诸实践的行动与冲动)   |
+-------------------------------------------------------------+
```

## 2. 形式化论证三段论 (Formal Syllogism)

- **大前提 ($P_1$)**：主体的自由与心智安宁并不取决于外部环境的绝对控制，而取决于对自身注意力和判断力（Hēgemonikon）的完全自主。
- **小前提 ($P_2$)**：自动化的反应机制会让主体随波逐流地沦为外部刺激与算法强化的奴隶。
- **归谬 ($R$)**：若主体放弃注意力审查而将情绪与行动交由即时反馈主宰，则无论获得多少物质财富与信息，其心智依然处于绝对受役状态。
- **结论 ($C$)**：∴ 现代知识工作者必须建立主动的 Prosochē 审查机制，将注意力视作第一不可让渡的生存资产。
