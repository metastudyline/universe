# E01 元规划｜我们要用多久做什么，为什么这么排

## 一、 核心元问题
**一条学习路线的顺序能不能被客观地确定？**

学科逻辑顺序（如教科书从本体论、认识论到伦理学）往往掩盖了概念产生的真实历史困难。教学依赖关系（Pedagogical DAG）受两个客观约束：
1. **线性时间轴**（人类语言与认知的单向流动）；
2. **客观教学依赖**（不理解赫西俄德与荷马的份额 τιμή 与正义 δίκη，就无法理解苏格拉底为何受审，更无法理解亚里士多德《尼各马可伦理学》卷五与马克思《资本论》第一章的等价难题）。

---

## 二、 掌握六层次与判据标准

| 掌握层次 | 定义 | 验证动作 |
| :--- | :--- | :--- |
| **0 无知** | 不知道某个问题存在 | 盲区未被识别 |
| **1 未知** | 已经看见自己的空白 | 能提出具体的卡点问题 |
| **2 了解** | 能够辨认和复述概念 | 见到术语能认出原词 |
| **3 使用** | 能在新材料上调用逻辑 | 用四因分析新案例 |
| **4 掌握** | 脱离提示仍能闭卷推导 | 闭卷重构论证并指出薄弱环节 |
| **5 内化** | 概念参与每日判断与批判 | 能判别二手解读并开辟新学线 |

---

## 三、 四件出口资产
每个学习节点输出四项标准资产：
1. **术语卡**：七栏标准（原文原形、字面义、通行中译、英译、被丢掉的是什么、出处、文本原形）；
2. **论证重构**：闭卷复原论证步骤，标出前提与最薄弱一环；
3. **拓扑片段**：声明前置节点 ID 与掌握等级约束（0-5）；
4. **知识胶囊草稿**：元问题、一手材料清单、教案骨架与三档判据。
