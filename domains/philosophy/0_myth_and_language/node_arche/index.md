# 第一期 导论｜法庭、书桌与一条长路：哲学怎样成为一种生活

## 一、 为什么是本原（Archē）？
在荷马与赫西俄德的神话世界中，万物的发生归结于诸神的谱系（Theogony）。然而，当米利都的泰勒斯提出「水是万物的本原」时，人类思维发生了根本性的范式跃迁：他不再求助于具有拟人意志的神祇，而是试图用经验可感、理性可论证的自然实体解释万物的统一性。

## 二、 核心论证重构
1. **前提 1**：一切生命均依赖湿度滋养，种子本质具有潮湿属性。
2. **前提 2**：多样性的世界必须存在一个底层的恒常基质，否则变化不可理解。
3. **推论**：水（Hydōr）作为无处不在的物理相变实体，是支持万物生灭的最初本原。
