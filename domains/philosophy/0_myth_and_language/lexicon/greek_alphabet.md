## 二、 双元音与变音符号

### 1. 气息符号 (Breathing Marks)
- **强送气符 (Rough Breathing, ἁ)**：表示词首元音或 ρ 前带有 /h/ 音（如 ὕβρις -> *hybris*, ὅρκος -> *horkos*）。
- **弱等气符 (Smooth Breathing, ἀ)**：表示词首元音不带 /h/ 音（如 ἀρχή -> *archē*, ἀλήθεια -> *alētheia*）。

### 2. 重音符号 (Accents)
- **锐重音 (Acute, ά)**：声调上扬（可在最后三个音节）。
- **扬重音 (Circumflex, ᾶ / ῆ)**：升降调（只在长元音或双元音的最后两个音节）。
- **抑重音 (Grave, ὰ)**：平调替代（在词尾连读时）。

## 三、 多调键盘输入 (Greek Polytonic Typing)

在 macOS / Windows / Linux 系统设置中添加 **Greek Polytonic (希腊语-多调)** 键盘：
- 键入弱送气符 `ἀ`：先按 `]` 再按元音 `a`
- 键入强送气符 `ἁ`：先按 `Shift + ]` 再按元音 `a`
- 键入锐重音 `ά`：先按 `;` 再按元音 `a`
- 键入扬重音 `ᾶ`：先按 `Shift + [` 再按元音 `a`
- 词尾 ς：直接按 `w` 键
